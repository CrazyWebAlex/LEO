# LEO 🤖

**AI-powered website assistant for CrazyWebAlex.**

LEO is my own browser-based assistant designed to help visitors understand websites, web design, pricing, landing pages, SEO and technical terms without unnecessary jargon.

🌐 **Live version:** https://crazywebalex.com/leo.html

---

## What LEO does

- Answers common website and web design questions
- Explains pricing and service options
- Helps visitors understand SEO and technical terminology
- Provides information about landing pages and web applications
- Guides visitors toward the right contact option
- Works directly in the browser

---

## Project focus

LEO combines a custom frontend with structured content and interactive assistance.

The project focuses on:

- Responsive Webdesign
